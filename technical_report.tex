\section*{System Overview}

The system answers open-ended questions about short films. Its basic unit is
the movie rather than the individual question: all questions for one film are
answered in a shared multimodal context. This preserves information that is
otherwise difficult to recover independently, including aliases, changing
relationships, event order, causes, and the ending state.

The artifact releases the executable inference and submission utilities,
configuration guidance, tests, chart data, and this report. Videos, subtitles,
model weights, generated answers, credentials, account identifiers, and
evaluation records remain external inputs.

\section*{Method}

For movie $m$, let $E_m$ denote the shared evidence and $Q_m$ its complete
question set. The runner makes one request and receives one answer bank:
\[
  (E_m,Q_m) \longrightarrow
  \{a_{m,1},a_{m,2},\ldots,a_{m,n_m}\}.
\]
The evidence packet contains a timestamped transcript and a chronological
frame pack. The prompt asks for concise, evidence-supported English answers
with exact question IDs. It requires the model to maintain cross-question
consistency and forbids unsupported visual details.

Frames are sampled in chronological order, resized to a fixed maximum side,
JPEG encoded, and marked with their timestamps. Long transcripts use a
deterministic head-and-tail bound. The model is accessed through an
OpenAI-compatible Responses endpoint; the credential is read from an
environment variable at runtime.

\section*{Inference Pipeline}

The deterministic pipeline groups rows by \texttt{video\_id}, parses timestamped
subtitle cues, samples chronological frames, sends one request with all movie
questions, and validates the complete JSON bank before persistence. The final
conversion writes the competition CSV. Missing IDs, empty answers, malformed
JSON, and incomplete movie banks are errors; partial responses are never merged.

\section*{Results and Ablations}

Figure~2 reports a frozen six-movie, 60-question local diagnostic using one
semantic evaluator. Joint answering reaches 27/60, independent calls 18/60,
no frames 24/60, Target16 29/60, and Dense48 30/60. The results support joint
context and bound simple frame-budget changes.

\section*{Limitations}

The method depends on transcript quality, visual coverage, endpoint behavior,
and context budget. Data and weights are external inputs, and endpoint
availability is not guaranteed. Reproduction requires authorized access and
the included schema audit.
